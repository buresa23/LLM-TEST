**Prime Number Checker Function**
================================

The following is a Python function that checks whether a given number is a prime number.

```python
def is_prime(n):
    """
    Checks if a given number is a prime number.

    Args:
        n (int): The number to check.

    Returns:
        bool: True if the number is prime, False otherwise.
    """
    if n <= 1:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

# Example usage:
print(is_prime(5))  # Output: True
print(is_prime(6))  # Output: False
print(is_prime(23))  # Output: True
```

**Explanation**
---------------

This function works by checking if the input number `n` is divisible by any number between 2 and the square root of `n`. If it finds a divisor, it immediately returns `False`. If it checks all numbers up to the square root of `n` without finding a divisor, it returns `True`.

The time complexity of this function is O(√n), making it efficient for large inputs. However, for very large numbers, you may want to use amore advanced primality test like the Miller-Rabin primality test.

### Python Function

```python
def is_prime(n):
    """
    Checks if a given number is a prime number.
    Returns True if the number is prime, False otherwise.
    """
    # Numbers less than or equal to 1 are not prime
    if n <= 1:
        return False
    
    # 2 is the only even prime number
    if n == 2:
        return True
    
    # Eliminate even numbers greater than 2
    if n % 2 == 0:
        return False
    
    # Check for factors from 3 up to the square root of n
    # We check only odd numbers to optimize performance
    for i in range(3, int(n**0.5) + 1, 2):
        if n % i == 0:
            return False
            
    return True

# --- Examples of usage ---

# Example 1: Checking a prime number (e.g., 29)
number = 29
result = is_prime(number)
print(f"Is {number} a prime number? {result}")  # Output: Is 29 a prime number? True

# Example 2: Checking a non-prime number (e.g., 15)
number = 15
result = is_prime(number)
print(f"Is {number} a prime number? {result}")  # Output: Is 15 a prime number? False

# Example 3: Checking a number less than 2 (e.g., 0)
number = 0
result = is_prime(number)
print(f"Is {number} a prime number? {result}")  # Output: Is 0 a prime number? False
```

### Explanation of the Logic:
1.  **Input Validation**: The function immediately returns `False` for numbers less than or equal to 1, as these are not prime.
2.  **Handling 2**: The number 2 is the only even prime number, so the function returns `True` specifically for it.
3.  **Eliminating Even Numbers**: The function checks if the number is even. If it is, it returns `False` immediately (except for 2).
4.  **Efficiency Optimization**: It checks for factors only up to the square root of the number. This is a mathematical optimization because if a number has a factor larger than its square root, it must also have a factor smaller than its square root.
5.  **Iteration**: It loops through odd numbers starting from 3 up to the square root of `n`. If any of these numbers divide `n` evenly, itreturns `False`. If the loop finishes without finding any divisors, it returns `True`.

** Funkce pro ověření prvočísla**
=====================================

Následujete Pythonische funkci, která ověří, zda given Number je prvočíslo:
```python
def je_prvočislo(number):
    """
    Ověří, zda given Number je prvočíslo.

    Args:
        number (int): Prvočíslo, cui se ověří.

    Returns:
        bool: Účastník, zda number je prvočíslo.
    """
    if number <= 0:
        return False
    sqrt = int(number ** 0.5)
    if sqrt * sqrt == number:
        return True
    return False
```
